# templates

`RUNBOOK-ab-template.md` - an EMPTY GPU A/B runbook: preflight table, the gates G0-G4, a blank arm-queue table and the
pre-registered verdict rules (ADOPT / REFUTE / UNDECIDED) with every threshold left for you to fill from your own
measured noise floor. Copy it per GPU session into your private notes; the plan it belongs to is locked with
`../../image/replica/lock_cells.sh` (or your own gate) before the box is switched on.

The plan / pre-registration and ledger templates themselves live with the memory skeleton of this package.
